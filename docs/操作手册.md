## 项目使用说明

### 1. 环境准备

#### 1.1 前置要求

| 组件 | 版本要求 | 用途 |
|------|----------|------|
| JDK | 17+ | Java运行环境 |
| Maven | 3.8+ | 项目构建工具 |
| GraalVM | 23.1.0+ | Native Image编译（可选） |

#### 1.2 环境验证

```bash
# 检查Java版本
java -version

# 检查Maven版本
mvn -version

# 检查GraalVM（如需Native Image）
gu --version
```

### 2. 项目结构

```
java-harness/
├── java-harness-foundation/         # 基础层：核心接口和工具类
├── java-harness-protocol/          # 协议层：Hook协议定义和编解码
├── java-harness-security/          # 安全层：Guardrail规则实现
├── java-harness-workflow/          # 工作流层：流程编排
├── java-harness-collaboration/     # 协作层：多代理协作
├── java-harness-cli/               # CLI层：命令行接口
├── java-harness-service/           # 服务层：Spring Boot服务
├── java-harness-tools/             # 工具层：辅助工具集
├── java-harness-distribution/      # 分发层：打包配置
├── java-harness-shared/            # 共享模块（遗留）
└── docs/                           # 文档目录
```

### 3. 快速开始

#### 3.1 克隆项目

```bash
# 克隆仓库
git clone https://github.com/your-org/java-harness.git
cd java-harness
```

#### 3.2 编译项目

```bash
# 使用构建脚本
./build.sh

# 或使用Maven命令
mvn clean compile
mvn test
mvn package
```

#### 3.3 运行项目

```bash
# 方式1：运行JAR版本
java -cp java-harness-cli/target/harness-cli-4.0.0-java-SNAPSHOT.jar \
     com.chachamaru.harness.cli.HarnessCli --version

# 方式2：运行Native Image版本（需先编译）
./java-harness-cli/target/harness --version
```

### 4. 核心功能使用

#### 4.1 Hook协议处理

```bash
# 测试Hook输入
echo '{
  "session_id": "test-session",
  "transcript_path": "/tmp/transcript.jsonl",
  "cwd": "/project",
  "permission_mode": "default",
  "hook_event_name": "PreToolUse",
  "tool_name": "Bash",
  "tool_input": {"command": "echo test"},
  "plugin_root": "/plugin"
}' | java -cp harness-cli-4.0.0.jar \
        com.chachamaru.harness.cli.HarnessCli
```

#### 4.2 Guardrail安全规则

项目内置15个安全规则（R01-R15），可自动检测和阻止危险操作：

```bash
# 测试危险命令阻止
echo '{
  "session_id": "test",
  "hook_event_name": "PreToolUse",
  "tool_name": "Bash",
  "tool_input": {"command": "sudo rm -rf /"}
}' | java -cp harness-cli.jar \
        com.chachamaru.harness.cli.HarnessCli

# 应该返回DENY决策
```

#### 4.3 配置文件

创建 `harness.yaml` 配置文件：

```yaml
# Hook配置
hook:
  enabled: true
  timeout: 10000  # 10秒超时

# Guardrail配置
guardrail:
  enabled: true
  rules:
    - R01  # 阻止提权命令
    - R02  # 保护敏感路径
    - R03  # 阻止重定向绕过
    # ... 更多规则

# 日志配置
logging:
  level: INFO
  file: /var/log/harness/harness.log
```

## 导出操作说明

### 1. 导出类型

#### 1.1 JAR文件导出

```bash
# 导出标准JAR文件
mvn clean package

# 输出位置
# - java-harness-cli/target/harness-cli-4.0.0-java-SNAPSHOT.jar
# - java-harness-service/target/harness-service-4.0.0-java-SNAPSHOT.jar
```

#### 1.2 可执行JAR导出

```bash
# 导出包含所有依赖的可执行JAR
mvn clean package -Dmaven.test.skip=true

# 使用maven-assembly-plugin
mvn clean package assembly:single

# 输出位置
# - java-harness-cli/target/harness-cli-*-jar-with-dependencies.jar
```

#### 1.3 Native Image导出

```bash
# 编译为原生可执行文件
cd java-harness-cli
mvn -Pnative native:compile -DskipTests

# 输出位置
# - java-harness-cli/target/harness
# - java-harness-cli/target/harness.exe (Windows)
```

### 2. 导出产物说明

| 产物类型 | 文件位置 | 优点 | 缺点 |
|---------|----------|------|------|
| 标准JAR | `target/*-SNAPSHOT.jar` | 体积小，快速构建 | 需要JDK运行时 |
| 依赖JAR | `target/*-jar-with-dependencies.jar` | 单文件，包含所有依赖 | 体积较大 |
| Native Image | `target/harness` | 启动快(<100ms)，无JVM依赖 | 编译时间长，平台相关 |

### 3. 产物验证

```bash
# 验证JAR文件
java -jar harness-cli-4.0.0.jar --version

# 验证Native Image
./harness --version

# 性能测试
time ./harness --version  # 应该 < 100ms
```

## 打包操作说明

### 1. 标准打包流程

#### 1.1 完整打包

```bash
# 执行完整打包流程
./build.sh

# 等价于以下命令
mvn clean compile
mvn test
mvn package -DskipTests
```

#### 1.2 分步打包

```bash
# 步骤1：清理
mvn clean

# 步骤2：编译
mvn compile

# 步骤3：测试（可选）
mvn test

# 步骤4：打包
mvn package
```

### 2. 模块化打包

#### 2.1 打包特定模块

```bash
# 只打包CLI模块
mvn package -pl java-harness-cli -am

# 只打包Service模块
mvn package -pl java-harness-service -am

# 打包多个模块
mvn package -pl java-harness-cli,java-harness-service -am
```

#### 2.2 打包并跳过测试

```bash
# 快速打包（跳过测试）
mvn package -DskipTests

# 打包并跳过测试编译
mvn package -Dmaven.test.skip=true
```

### 3. Native Image打包

#### 3.1 前置准备

```bash
# 安装GraalVM
brew install --cask graalvm-jdk23  # macOS
sdk install java 23-gral          # Linux

# 安装native-image工具
gu install native-image

# 设置环境变量
export GRAALVM_HOME=/path/to/graalvm
export PATH=$GRAALVM_HOME/bin:$PATH
```

#### 3.2 Native Image编译

```bash
# 编译CLI为Native Image
cd java-harness-cli
mvn -Pnative native:compile -DskipTests

# 编译Service为Native Image
cd java-harness-service
mvn -Pnative native:compile -DskipTests
```

#### 3.3 GraalVM配置

创建 `native-image.properties`：

```properties
# 内存配置
Args = -H:+ReportExceptionStackTraces \
       -H:ResourceConfigurationFiles=resources.json \
       -H:ReflectionConfigurationFiles=reflection.json \
       -J-Xmx8g

# 优化选项
Args = --verbose \
       --no-fallback \
       --enable-https \
       --install-exit-handlers

# 静态编译（可选）
# Args = --static
```

### 4. 分发包打包

#### 4.1 创建分发包

```bash
# 使用maven-assembly-plugin创建分发包
mvn clean package assembly:single

# 自定义打包配置
mvn package -DdescriptorId=jar-with-dependencies
```

#### 4.2 创建发布包

```bash
# 创建发布目录
mkdir -p release/harness-4.0.0
cd release/harness-4.0.0

# 复制产物
cp ../../java-harness-cli/target/harness-cli-*-jar-with-dependencies.jar ./harness-cli.jar
cp ../../java-harness-cli/target/harness ./harness
cp -r ../../docs ./docs
cp ../../README.md ./README.md
cp ../../LICENSE ./LICENSE

# 创建tar包
cd ../..
tar czf harness-4.0.0.tar.gz release/harness-4.0.0/

# 创建zip包（Windows）
zip -r harness-4.0.0.zip release/harness-4.0.0/
```

### 5. Docker打包

#### 5.1 创建Dockerfile

```dockerfile
FROM amazoncorretto:17

# 设置工作目录
WORKDIR /app

# 复制JAR文件
COPY java-harness-cli/target/harness-cli-*-jar-with-dependencies.jar /app/harness.jar

# 设置环境变量
ENV HARNESS_LOG_LEVEL=INFO
ENV HARNESS_HOOK_TIMEOUT=10000

# 暴露端口（如需）
EXPOSE 8080

# 启动命令
ENTRYPOINT ["java", "-jar", "/app/harness.jar"]
```

#### 5.2 构建Docker镜像

```bash
# 构建镜像
docker build -t harness:4.0.0 .

# 运行容器
docker run -d --name harness harness:4.0.0

# 测试容器
docker exec harness java -jar /app/harness.jar --version
```

### 6. 打包优化

#### 6.1 减小JAR体积

```bash
# 排除不必要的依赖
mvn package -Dmaven.test.skip=true \
  -Dmaven.compiler.excludeModule=spring-boot-devtools

# 使用ProGuard优化（需要配置）
mvn package proguard:proguard
```

#### 6.2 并行构建

```bash
# 启用并行构建
mvn -T 4 clean package  # 4线程并行

# 自动检测线程数
mvn -T 1C clean package  # CPU核心数并行
```

#### 6.3 增量编译

```bash
# 启用增量编译
mvn compile -Dmaven.compiler.incremental=true

# 增量打包
mvn package -Dmaven.compiler.incremental=true
```

### 7. 质量检查

```bash
# 运行完整测试套件
mvn verify

# 生成测试报告
mvn surefire-report:report

# 代码覆盖率（需要配置JaCoCo）
mvn jacoco:report

# 静态代码分析
mvn checkstyle:check
mvn pmd:check
```

## 故障排除

### 1. 构建问题

#### 1.1 Maven依赖下载失败

```bash
# 问题：依赖无法下载
# 解决：使用国内镜像
```

在 `~/.m2/settings.xml` 中配置：

```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <name>Aliyun Maven</name>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

#### 1.2 编译错误

```bash
# 清理并重新编译
rm -rf ~/.m2/repository
mvn clean install -U

# 增加编译内存
export MAVEN_OPTS="-Xmx2g -XX:MaxMetaspaceSize=512m"
mvn clean package
```

#### 1.3 测试失败

```bash
# 跳过失败测试
mvn package -Dmaven.test.failure.ignore=true

# 只运行特定测试
mvn test -Dtest=HookCodecTest

# 调试测试
mvn test -X
```

### 2. Native Image问题

#### 2.1 GraalVM编译失败

```bash
# 检查GraalVM版本
java -version
gu --version

# 增加编译内存
export JAVA_OPTS="-Xmx8g"
mvn -Pnative native:compile

# 查看详细日志
mvn -Pnative native:compile -X
```

#### 2.2 运行时错误

```bash
# 配置反射和资源文件
echo '[
  {"name": "com.chachamaru.harness.**"}
]' > reflection.json

# 重新编译
mvn -Pnative native:compile -DskipTests
```

### 3. 运行问题

#### 3.1 启动失败

```bash
# 检查Java版本
java -version  # 需要 JDK 17+

# 检查JAR完整性
jar tf harness-cli.jar

# 详细错误信息
java -Xdiag -jar harness-cli.jar --version
```

#### 3.2 性能问题

```bash
# JVM性能调优
java -Xms256m -Xmx512m \
     -XX:+UseG1GC \
     -jar harness-cli.jar

# Native Image性能
time ./harness --version  # 应该 < 100ms
```

## 常见问题

### Q1: 如何选择JAR版本还是Native Image版本？

**答:**
- **JAR版本**: 适合开发和测试环境，启动稍慢(~2s)，但兼容性好
- **Native Image版本**: 适合生产环境，启动快(<100ms)，但编译时间长

### Q2: 打包时如何排除某些模块？

**答:**
```bash
# 使用pl参数指定要打包的模块
mvn package -pl java-harness-cli,java-harness-service -am
```

### Q3: 如何创建跨平台的Native Image？

**答:**
```bash
# 需要在目标平台上分别编译
# Linux平台
mvn -Pnative native:compile  # 生成 harness-linux

# Windows平台
mvn -Pnative native:compile  # 生成 harness.exe

# macOS平台
mvn -Pnative native:compile  # 生成 harness-macos
```

### Q4: 如何减小发布包体积？

**答:**
```bash
# 使用依赖排除
mvn package -Dmaven.test.skip=true

# 使用ProGuard压缩
mvn package proguard:proguard

# Native Image已经过优化，通常比JAR+JVM更小
```

### Q5: 打包命令执行时间过长怎么办？

**答:**
```bash
# 并行构建
mvn -T 4 clean package

# 跳过测试
mvn package -DskipTests

# 离线模式（如果依赖已下载）
mvn -o package
```
