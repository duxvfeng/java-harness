## 📱 方式一：Claude Code Desktop

### 点击式安装流程

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 打开 Claude Code Desktop                            │
└─────────────────────────────────────────────────────────────┘
           点击应用图标 → 启动应用


┌─────────────────────────────────────────────────────────────┐
│ Step 2: 进入插件管理                                         │
└─────────────────────────────────────────────────────────────┘
     左下角 ⚙️ → Settings → Plugins → Marketplace


┌─────────────────────────────────────────────────────────────┐
│ Step 3: 搜索 Java Harness                                    │
└─────────────────────────────────────────────────────────────┘
     搜索框输入: "duxvfeng/java-harness" → 🔍 搜索


┌─────────────────────────────────────────────────────────────┐
│ Step 4: 选择插件                                             │
└─────────────────────────────────────────────────────────────┘
     在结果中找到 "Java Harness - Claude Code 安全框架"
     ↓
     [查看详情] → 阅读 → [返回]


┌─────────────────────────────────────────────────────────────┐
│ Step 5: 安装插件                                             │
└─────────────────────────────────────────────────────────────┘
     点击 [Install] 按钮
     ↓
     选择版本: v4.0.0 (推荐)
     ↓
     等待安装... ⏳ (1-2分钟)
     ↓
     ✅ 安装成功!


┌─────────────────────────────────────────────────────────────┐
│ Step 6: 配置插件 (可选)                                      │
└─────────────────────────────────────────────────────────────┘
     [Settings] → 根据需要配置 → [Apply]


┌─────────────────────────────────────────────────────────────┐
│ Step 7: 重启应用                                             │
└─────────────────────────────────────────────────────────────┘
     关闭应用 → 重新打开 → 插件自动加载
```

## 💻 方式二：Claude Code CLI

### 命令行安装流程

```bash
# ═════════════════════════════════════════════════════════════
# Step 1: 打开终端
# ═════════════════════════════════════════════════════════════
# • Windows: PowerShell, CMD, Git Bash
# • macOS: Terminal, iTerm2
# • Linux: 任何终端

# ═════════════════════════════════════════════════════════════
# Step 2: 更新 Claude Code (可选但推荐)
# ═════════════════════════════════════════════════════════════
claude update
# 输出: Updating Claude Code... ✅

# ═════════════════════════════════════════════════════════════
# Step 3: 搜索插件 (可选)
# ═════════════════════════════════════════════════════════════
claude plugin search java-harness
# 输出:
# Found plugin: duxvfeng/java-harness
# Description: Java implementation of Claude Code Harness
# Version: 4.0.0

# ═════════════════════════════════════════════════════════════
# Step 4: 查看插件详情 (可选)
# ═════════════════════════════════════════════════════════════
claude plugin info duxvfeng/java-harness
# 输出详细的插件信息

# ═════════════════════════════════════════════════════════════
# Step 5: 安装插件 (核心命令)
# ═════════════════════════════════════════════════════════════
claude plugin install duxvfeng/java-harness@v4.0.0
# 输出:
# Installing plugin duxvfeng/java-harness@v4.0.0...
# Downloading plugin files...
# Installing dependencies...
# ✅ Plugin installed successfully!

# ═════════════════════════════════════════════════════════════
# Step 6: 验证安装
# ═════════════════════════════════════════════════════════════
claude plugin list | grep java-harness
# 输出: java-harness  4.0.0  duxvfeng  [active]

# ═════════════════════════════════════════════════════════════
# Step 7: 测试插件
# ═════════════════════════════════════════════════════════════
echo 'test' | claude plugin invoke java-harness
# 输出: JSON 响应表示插件正常工作

# ═════════════════════════════════════════════════════════════
# ✅ 安装完成！开始使用 Java Harness
# ═════════════════════════════════════════════════════════════
```
