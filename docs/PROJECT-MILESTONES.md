## 📊 项目概览

Java Harness 是一个专业的 AI 辅助开发框架，为大型 Java 项目提供智能化的开发工作流和任务管理。

### 核心特性
- 🎯 **智能任务管理**: 基于 Plans.md 的任务分解和追踪
- 🔄 **会话管理**: Token 感知的自动保存和恢复系统
- 🌐 **双平台支持**: 同时支持 Claude Code 和 Codex CLI
- 🧪 **完整测试**: 多层次的测试验证体系
- 📚 **丰富文档**: 用户指南、开发文档、API参考
