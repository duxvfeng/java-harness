# Harness Project Documentation

本目录集中存放被 `skills/` 和 `skills-codex/` 工作流直接引用的项目设计、规格、策略和操作文档。

## 目录

- `analysis/`：分析报告
- `architecture/`：架构设计
- `dual-platform/`：Java/Go 双平台边界
- `plans/`：计划、规格正本和团队模式
- `superpowers/specs/`：功能设计规格
- `user-guide/`、`user-guides/`：技能工作流需要的用户指南
- 根目录：宿主配置、策略、沙箱和测试指南

## 约定

技能引用本目录中的文档时，统一使用 `docs/harness-project/...` 路径。新增会被技能直接消费的项目设计文档，也应放在本目录或其对应子目录中。
