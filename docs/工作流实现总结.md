## 🚀 使用方式

### 编程接口

```java
// 创建工作流引擎
WorkflowLoader loader = new WorkflowLoader();
WorkflowEngine engine = new WorkflowEngine(loader, skillRegistry);

// 执行工作流
WorkflowExecutionResult result = engine.executeWorkflow("plan", input);

// 检查结果
if (result.isSuccess()) {
    System.out.println("工作流执行成功");
    System.out.println("执行摘要: " + result.getSummary());
}
```

### 运行示例

```bash
# 编译项目
cd java-harness-workflow
mvn clean compile

# 运行集成示例
mvn exec:java -Dexec.mainClass="com.chachamaru.harness.workflow.integration.WorkflowIntegrationExample"

# 输出示例：
# === 可用工作流列表 ===
# - init: 初始化项目并设置开发工作流
# - plan: 更新 Plans.md 并分解任务的阶段
# - work: 执行计划任务并生成可运行代码的阶段
# - review: 检查代码质量并提出改进建议的阶段
```
